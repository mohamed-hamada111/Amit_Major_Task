(EDA)** web application built using Streamlit.

🔗 **Live App:**\
https://depiml-nkbhtcsapp52rnlhoovynyp.streamlit.app/

------------------------------------------------------------------------

## 📌 Project Overview

This project focuses on building a reusable and structured **data
preprocessing system** that helps users:

-   Explore datasets
-   Clean missing data
-   Detect duplicates
-   Analyze distributions
-   Identify outliers
-   Visualize relationships
-   Understand feature correlations

The application provides a simple and interactive interface to perform
all preprocessing steps before building any Machine Learning model.

------------------------------------------------------------------------

## 🚀 Features

### 🔹 Dataset Overview

-   Display dataset shape
-   Show data types
-   Count unique values per column
-   Descriptive statistics

### 🔹 Data Cleaning

-   Detect null values
-   Calculate null ratios
-   Detect duplicated records
-   Drop duplicates
-   Handle missing values:
    -   Mean (numerical)
    -   Median (numerical)
    -   Mode (categorical)
-   Automatically drop columns with high missing ratio (≥30%)

### 🔹 Data Visualization

-   Distribution plots (with outlier filtering)
-   Boxplots for outlier detection
-   Barplots for feature relationships
-   Correlation heatmap (numerical features)
